[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/Ibrahist/ForgeDesk)

[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/Ibrahist/ForgeDownloadManager)

An open-source, cross-platform download manager powered by a high-performance Rust engine.

**Highlights**

- Pause, resume, and crash recovery.

- Bandwidth management and scheduling.
- Browser extension integration.
- HLS/DASH media downloading.
- Desktop application and command-line interface.
